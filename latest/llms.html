For LLMs ​

sqlalchemy-seedling provides machine-readable documentation endpoints so AI assistants and LLM-powered tools can understand this library accurately.

llms.txt ​

A concise index of the documentation — titles, descriptions, and links. Follows the llms.txt standard.

llms-full.txt ​

The full content of every documentation page in a single plain-text file. Best for feeding directly into a context window.
